# RIGS-LLM

This repository provides selected research artifacts associated with RIGS-LLM, including experimental results, LLM-related utilities, autonomous driving simulation resources, and generated scenario datasets.

## Repository Structure

### 01_Experimental_Results

Contains the experimental results presented in the paper, including high-resolution TIFF figures and their associated data files. 

### 02_LLM_Adaptation

Provides Qwen3.5-27B-related configurations and Python utilities for language model inference, text retrieval, knowledge graph processing, experiment management, and data visualization. The official Qwen3.5-27B model is available from [Hugging Face](https://huggingface.co/Qwen/Qwen3.5-27B).

### 03_ADS_Simulation

Contains selected autonomous driving simulation resources developed using PreScan, MATLAB, and Simulink. The included experiments and scenario configurations demonstrate the organization and execution of scenario-based autonomous driving tests.

### 04_Scenario_Dataset

Provides generated autonomous driving scenario examples, including scenario descriptions, method comparison materials, visualization results, and logical and concrete scenario data. These materials illustrate scenario representation, comparison, and downstream transformation.
